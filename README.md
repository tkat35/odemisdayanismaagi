# Ödemiş Dayanışma Ağı – Demo

Durum: TASLAK (2026-11-19) · Kaymakamlık brifingi (20.11.2026) için tanıtım demosu. Gerçek platform değildir.

- Tek dosya: `index.html`. Sunucu, veritabanı ve internet bağlantısı gerekmez; çift tıklayınca tarayıcıda açılır.
- Tüm kişiler ve eşyalar örnek veridir. Girilen veriler yalnızca o tarayıcının hafızasında (localStorage) tutulur, hiçbir yere gönderilmez.
- Üstteki "Demoyu sıfırla" düğmesi başlangıç verilerine döndürür.

## GitHub'a yükleme
`github.com/tkat35/odemisdayanismaagi` → Add file → Upload files → `index.html` → Commit.
Yayın için (isteğe bağlı): Settings → Pages → Branch: main, klasör: / (root). Sayfa `https://tkat35.github.io/odemisdayanismaagi/` adresinde açılır.

## Toplantıda gösterim sırası (yaklaşık 3 dakika)
1. Vitrin: onaylı eşyalar, kategori filtresi, talep kuralları.
2. Kayıt ol → Bağışçı → formu doldur → eşya ekle (adım 1).
3. Yönetim: Kızılay → İnceleme bekleyen → Onayla ve vitrinde yayımla (adım 2–3).
4. Çıkış → Kayıt ol → İhtiyaç sahibi → kayıt (adım 4) → Yönetim: SYDV → Onayla.
5. Vitrin → yeni eşyada "Talep et" (adım 5).
6. SYDV → Ürün talepleri → Tahsis et (adım 6). Ali Şahin örneğinde 90 gün / 1 yıl kural uyarısı görünür.
7. Kızılay → Lojistik → Bağışçıdan teslim alındı → İhtiyaç sahibine teslim edildi (adım 7–8).
8. Kaymakamlık özeti: sayılar ve işlem geçmişi. Zil simgesi: kullanıcıya giden sistem içi bildirimler.

Kısa yol: Giriş yap ekranında hazır örnek hesaplar var (şifre yok).
